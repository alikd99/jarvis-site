Privacy policy

Last updated: 4 November 2026

Who uses Jarvis

Jarvis is a personal app used only by its owner. It is not offered to the public, and nobody else can sign up or use it.

Google data Jarvis accesses

With the owner's permission, Jarvis accesses the owner's own Google account:

  • Gmail: read email and send email.
  • Google Calendar: read events and create events.
  • Google Tasks: read, add and complete tasks.
  • Google Contacts: read only.

Jarvis uses this data only to carry out requests the owner makes, such as reading new email aloud, sending an email the owner dictated, or adding an event.

Where data is processed and stored

Jarvis runs on the owner's PC, and the data is processed there. There is no Jarvis server. The Google sign-in token is stored only on that PC.

AI processing

To answer requests and summarize email, Jarvis sends the relevant text to the AI provider Groq. Only the text needed for the request is sent.

Other services

  • Jarvis speaks its replies using Microsoft's online text-to-speech service, so the text of a spoken reply is sent there to be turned into audio.
  • If the owner uses the optional Telegram channel, the owner's messages and Jarvis's replies pass through Telegram to reach the owner's phone.

What Jarvis never does

Data is never sold, never shared for advertising, and never used to train AI models.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
